# HW4 — промежуточное представление, CFG и оптимизации Funny

```
исходник -> лексер HW1 -> парсер HW2 -> семантика HW3 -> аннотированный AST
          -> IR -> CFG -> оптимизации -> живость -> граф конфликтов -> раскраска
```

Каталоги `../lexer`, `../parser` и `../sema` подключаются только на чтение. Реализация, тесты, документация и примеры HW4 находятся в `ir/`.

## Сборка и запуск

```sh
cd ir
make test
./build/funny_ir examples/optimization.fn
./build/funny_ir --format json examples/optimization.fn
./build/funny_ir --function compute \
  --cfg-dot /tmp/cfg.dot \
  --interference-dot /tmp/interference.dot \
  examples/optimization.fn
```

CLI печатает IR до и после оптимизаций и метрики для каждой функции. Синтаксические и семантические ошибки предыдущих этапов выводятся в `stderr`; IR для ошибочной программы не строится.

Коды возврата: `0` — успех, `1` — ошибка исходной программы, `2` — ошибка запуска или внутреннего формата IR.

## Флаги оптимизаций

| Флаг | Действие |
|---|---|
| `--no-const-prop` | отключить локальное распространение и свёртку констант |
| `--no-algebra` | отключить алгебраические упрощения (`x+0`, `x*1`, `x*0`, `x/1` и булевы аналоги) |
| `--no-dce` | отключить локальное удаление мёртвого кода |
| `--no-opt` | отключить все три оптимизации |
| `--format text\|json` | выбрать текстовый или JSON-вывод |
| `--function NAME` | выбрать функцию для DOT-графов (по умолчанию первая) |
| `--cfg-dot FILE` | записать CFG выбранной функции в DOT |
| `--interference-dot FILE` | записать граф конфликтов и цвета в DOT |

Опции независимы: можно оставить включённым только нужный проход.

## Состав

| Файл | Назначение |
|---|---|
| `src/ir.{hpp,cpp}` | модель инструкций/операндов, текст/JSON, DOT, метрики |
| `src/generator.{hpp,cpp}` | перевод аннотированного AST в трёхадресный код |
| `src/analysis.{hpp,cpp}` | базовые блоки, CFG, живость, граф конфликтов, жадная раскраска |
| `src/optimizer.{hpp,cpp}` | константы, алгебраические правила, локальный DCE |
| `src/interpreter.{hpp,cpp}` | выполнение IR для проверки эквивалентности |
| `src/main.cpp` | CLI `funny_ir` |
| `tests/ir_tests.cpp` | модульные и интеграционные тесты |
| `docs/ir.md` | точный формат IR и API для следующего этапа/JVM |
| `examples/` | исходник, IR до/после, CFG и граф конфликтов |
| `REPORT_HW4.md` | краткий отчёт и результаты тестирования |
