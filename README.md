# funny-lexgen — HW1 (Funny): регулярки → НКА → ДКА → минимальный ДКА

```
data/tokens.txt 
    1) Томпсон НКА 
    2) ДКА + ловушка
    3) минимальный ДКА 
    4) output/dfa_table.{json,csv,hpp}
```

## Запуск

```sh
make test                 # сборка + генерация таблицы + все тесты
make gen                  # только сгенерировать output/dfa_table.* и REPORT.md
./build/standalone_lexer 'if x<=10 { y = 0; } // c'   # пример лексера на готовой таблице
```

## Файлы

| Файл | Что это |
|---|---|
| `data/tokens.txt` | регулярные выражения токенов: `ИМЯ SKIP\|TOKEN регулярка`, порядок = приоритет |
| `data/tests.jsonl` | тесты: `input` → `expected` (поток токенов; `"mode": "whole"` — принимает ли ДКА строку целиком или `REJECT`). Хорошие — `good_*`, плохие (ERR/REJECT) — `bad_*` |
| `src/funnylex.{hpp,cpp}` | весь конвейер, экспорт, лексер |
| `src/main.cpp` | CLI: строит автомат, пишет таблицу и `REPORT.md`, гонит `tests.jsonl` |
| `tests/tests.cpp` | тесты стадий: регулярки, приоритеты, ловушка, минимальность (сверка с алгоритмом Мура), случайная сверка ДКА до/после минимизации, экспорт, весь `tests.jsonl` |
| `examples/standalone_lexer.cpp` | лексер только на `output/dfa_table.hpp` — образец для T0 |
| `output/` | `dfa_table.json/csv/hpp` — готовая таблица переходов |
| `REPORT.md`, `Otchet_HW1.docx` | отчёт: регулярки, размеры ДКА до/после минимизации, ловушка |

Диалект регулярок: `a`, `\t \n \r`, `\x` (литерал), `[abc] [a-z] [^\n]`, `.`, `(..)`, `a|b`, `* + ?`.

## Ловушка и решения

- Ловушка — одно состояние: не принимающее, по всем 128 символам ведёт в себя; в неё идут все отсутствующие переходы. Её номер: `trap_state` (JSON), `is_trap` (CSV), `kTrapState` (.hpp). Байты ≥ 128 вне таблицы — потребитель отправляет их в ловушку сам (так делают `Lexer` и `standalone_lexer`).
- `INT = 0|[1-9][0-9]*`: ДКА не принимает `00` и `01` целиком; в потоке они режутся как `INT(0) INT(0)` / `INT(0) INT(1)`.
- По спецификации Funny `_` в идентификаторах нет: `my_var` → `IDENT(my) ERR(_) IDENT(var)`. Если нужен `_`, поменять регулярку `IDENT` в `data/tokens.txt` на `[a-zA-Z_][a-zA-Z0-9_]*`.
- Импликация — `->` (`→` не ASCII и уходит в ловушку); `=>` — тело формулы. Комментарий `//` кончается на `\r` или `\n`.
